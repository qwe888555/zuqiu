# 报名演示 · 球队端操作单

> 用途：在服务器上演示「球队账号 → 新建报名 → 选全部球员 → 上传材料 → 预检 → 提交审核」全流程。
> 前置版本：2026-11-11 代码。演示文件位于 `public/demo/`，部署后可通过 `/demo/...` 访问。

| 端 | 账号 | 密码 | 范围 |
|---|---|---|---|
| 球队端 | `team` | `Foot@2026` | 示例第一中学男子足球队（U15） |
| 市州审核 | `city` | `Foot@2026` | 示例市州 |
| 省级终审 | `province` | `Foot@2026` | 全省 |

## 二、先准备一个可报名的赛事组别（必须）

**为什么必须新建：** 球队 `示例第一中学男子足球队` 在现有开放赛事
`2026年四川省青少年校园足球联赛 · 初中男子组（U15）` 下已经有一份 **APPROVED** 报名
（`enr_858f879c2d664236b876`，24 人）。同一球队同一组别只允许一份有效报名，再次新建会被
`409 DUPLICATE_RESOURCE` 拒绝；已通过的报名也不能撤回/删除。

### 方案 A（推荐）：新建独立演示赛事

用 `admin` 登录 → 「赛事与组别」→「新建赛事」：

| 字段 | 填写 |
|---|---|
| 赛事名称 | 2026年校园足球报名演示 |
| 赛季 | 2026 秋季 |
| 赛事类别 | 省级联赛 |
| 报名开始时间 | 今天 00:00 |
| 报名截止时间 | 7 天后 23:59 |
| 状态 | 先保存为草稿 |

保存后点该赛事的「组别配置」→「新增组别」：

| 字段 | 填写 |
|---|---|
| 组别名称 | 初中男子组（U15·演示） |
| 学段 | 中学 |
| 性别 | 男 |
| 组别总名额（队） | 10 |
| 年龄下限 / 上限 | 13 / 15 |
| 每队人数上限 | **25**（球队现有 24 名现役球员，必须 ≥24） |
| 必备材料 | 勾选「盖章报名表」「学籍证明」 |

保存后回到赛事列表，点「发布并开放报名」。

> 方案 B：不建新赛事，在现有开放赛事里新增一个「初中男子组（U15·演示）」组别，
> 同样把人数上限设为 25。演示结束后该组别会保留一份报名，清理时需一并处理。
> 方案 A 隔离更干净，推荐 A。

## 三、新建报名单要填的表单

`team` 登录 → 左侧「报名单」→ 右上「新建报名」。

### 第 1 步：选择赛事

| 字段 | 必填 | 演示填写 |
|---|---|---|
| 参赛赛事 | 是 | 2026年校园足球报名演示 |
| 参赛组别 | 是 | 初中男子组（U15·演示） |
| 参赛球队（本队） | 是 | 示例第一中学男子足球队（U15 / 男 / 已认证） |

### 第 2 步：填写信息

| 字段 | 必填 | 演示填写 |
|---|---|---|
| 领队 / 联系人 | 是 | 球队端账号 |
| 联系电话 | 是 | `13800138000`（必须是 11 位手机号） |
| 备注 | 否 | 报名演示 |

### 第 3 步：确认创建

创建后进入报名详情页，状态为「草稿」。草稿也占用学校名额，演示时不要重复创建。

## 四、选择全部球员

详情页「球员名单」→「添加球员」：

1. 来源选「从球队名单选择」（默认）。
2. 表头勾选框 = 全选；当前可加入 **24 人**。
3. 底部显示「已选 24 人」后点「添加球员」。
4. 球队名单里的 2 名已离队成员不会进入现役可选列表，无需处理。
5. 从球队名单批量添加会沿用原有球衣号，不会重复。

## 五、报名材料

该组别要求两类材料，**都上传**才算齐全：

| 材料类型 | 要求 | 演示文件 |
|---|---|---|
| 盖章报名表（STAMPED_FORM） | 系统生成报名表 PDF → 打印盖章 → 扫描上传 | `/demo/stamped-form-demo.pdf` |
| 学籍证明（STUDENT_STATUS） | 学校教务部门出具、盖章后扫描 | `/demo/student-status-demo.pdf` |

操作：详情页「报名材料」→「上传材料」→ 选材料类型 → 拖入文件。
支持 PDF / JPG / PNG，单文件 ≤20MB。

演示文件说明：

- `stamped-form-demo.pdf`：系统按现有 24 人报名生成的报名表（2 页），可作盖章件上传的备用件。
  **推荐现场这样做**：新报名加完 24 人后，点详情页右上「下载报名表 PDF」，再把刚下载的这份
  PDF 直接当「盖章报名表」上传——这样赛事、组别、球员与当前报名完全一致。
- `student-status-demo.pdf`：按 24 名球员生成的学籍证明演示件，带「演示」水印与示例公章。
- 两个文件都只用于演示，正式环境请删除 `public/demo/`。
- 如果服务器还没部署这两个文件，也可现场用页面按钮：「下载报名表 PDF」；学籍证明在
  上传弹窗里点「下载学籍证明模板」。上传任意一个 PDF 也能完成流程演示。

## 六、预检与提交

1. 详情页右上「预检」：通过时提示无 ERROR；有问题会列出具体球员/材料。
2. 预检通过 →「提交审核」→ 确认提交。
3. 提交后生成快照，状态变为「待市州审核」，球队端不可直接改。
4. 换 `city` 登录 →「审核工作台」初审通过；再换 `province` 终审通过。
5. 审核通过后回到球队端，报名状态为「已通过」，可查看快照。

### 常见预检报错

| 提示 | 原因 | 处理 |
|---|---|---|
| 缺少必需材料 | 只传了一类材料 | 补传另一类（本组别两类都必需） |
| 人数超限 | 组别每队人数上限 < 24 | 把演示组别上限调到 25 |
| 球衣号已被占用 | 手动改号重复 | 用球队名单批量添加，不要手工改号 |
| 重复报名 | 同队同组已有有效报名 | 改用新建的演示赛事/组别 |
| 不在报名窗口 | 赛事未开放或已截止 | 管理员「发布并开放报名」/调整截止时间 |
